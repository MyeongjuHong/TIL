# 의상

같은 종류의 의상을 중복해 쓰지 않고 하루에 최소 1개의 의상을 입어야한다는 전제하에, 의상 조합 수를 반환하는 문제

입력은 2차배열의 형태로, 출력은 number로

종류도 있고, 값도 있고, Hash 카테고리에 있는 문제니 무조건 Map을 쓰면 되겠다 생각했는데 그 이후는 도저히 로직화하지 못해서 ai에게 힌트를 계속 받아가며 어떻게 해야할지 감을 잡았다.

## 문제 풀다가 도저히 모르겠을 때 스텝

1. 일단 30분 이상은 씨름해보기 (단, 절대 코드로 시작하지 말기, 손코딩으로 문제 분석이 먼저)

2. 왜 안되는지, 어디서 막혔는지 파악

3. 힌트를 받으며 차근차근 풀어보기

4. 도저히 안되겠으면 여러 방식의 풀이 확인

5. 다시 풀어보기

```js
function solution(clothes) {
  // kind => count
  const types = new Map();
  clothes.map((arr) => types.set(arr[1], (arr[1] ?? 0) + 1));
  console.log(types);
}
```

테스트 1  
입력값 〉 [["yellow_hat", "headgear"], ["blue_sunglasses", "eyewear"], ["green_turban", "headgear"]]  
출력 〉 Map(2) { 'headgear' => 'headgear1', 'eyewear' => 'eyewear1' }

테스트 2  
입력값 〉 [["crow_mask", "face"], ["blue_sunglasses", "face"], ["smoky_makeup", "face"]]  
출력 〉 Map(1) { 'face' => 'face1' }

```js
function solution(clothes) {
  // kind => count
  const types = new Map();
  clothes.map((arr) => types.set(arr[1], (types.get(arr[1]) ?? 0) + 1));
  // 값이 undefined면 기본값 value 0 설정
  console.log(types);
}
```

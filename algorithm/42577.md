### 해시 알고리즘

힌트

1. has()은 완성된 문자열만 검사

2. 앞에서부터 한글자씩 늘린 문자열 접두사 검사

3. 문자열을 앞에서부터 자르는 메서드가 뭘까?

```js
function solution(pb) {
  const set = new Set(pb);
  for (let el of pb) {
    for (let i = 0; i < el.length; i++) {
      if (set.has(el.slice(0, i))) return false;
    }
  }
  return true;
}
```

중첩 반복문이지만 배열의 길이를 20개로 제한해놔 시간 복잡도 O(n)

배열에 중복된 문자열이 없다거나, 배열의 길이도 짧아서 운이 좋았던 문제!

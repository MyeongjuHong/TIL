# 프로세스

## 내 풀이

```js
function solution(priorities, location) {
  const arr = [];
  let count = 0;
  for (let i = 0; i < priorities.length; i++) {
    arr.push([priorities[i], i]);
  }
  while (arr.length > 0) {
    const first = arr.shift();
    if (first[0] < Math.max(...arr.map((el) => el[0]))) {
      arr.push(first);
    } else {
      count += 1;
      if (first[1] === location) {
        return count;
      }
    }
  }
}
```

### 힌트

1. shift(), push()를 하면 인덱스 번호가 기존과 변경 -> 기존 인덱스 저장 필요  
   => 2차배열을 만들어 해당 요소에 대한 기존 인덱스 번호를 추가 저장

2. 변경된 (이차)배열 상태를 기준으로 최대값 반환 필요 -> 이차 배열 내 첫번째 요소만 골라 배열화  
   => `이차배열.map(el => el[0])`

### 효율성

#### 시간 복잡도 $O(n^2)$

- `shift()` $O(n)$

- `Math.max(...arr.map(el => el[0]))` $O(2n)$

- 도합 $3n$이지만 시간복잡도상 상수 탈락해 $O(n)$

- 그걸 n씩 반복해(그보다 많을 수도 있음) 총 $O(n \times n) = O(n^2)$

#### 공간 복잡도 $O(n)$

- 임시 배열만큼이 최대 크기

## 최적 풀이

```js
function solution(priorities, location) {
  const queue = priorities.map((priority, index) => [priority, index]);
  let answer = 0;

  while (queue.length) {
    const current = queue.shift();
    if (queue.some(([priority]) => current[0] < priority)) {
      // 현재 우선순위보다 더 큰 우선순위를 만나면 true (el => current[0] < el[0])
      queue.push(current); // 최우선순위가 아니기 때문에 다시 넣기
    } else {
      answer++;
      if (current[1] === location) return location;
    }
  }
}
```

> ### some()
>
> 배열 순차 검색 도중, **조건을 만족하는 요소**를 만나는 즉시 실행 중단  
> `true` 반환  
> 끝까지 돌아도 만족하는 요소 없을 땐 `false` 반환

## 내 풀이 vs 최적 풀이

- `for` + `push` 대신 `map` + `구조 분해 할당`
- `max` 대신 `some`
  - 굳이 map으로 배열을 만들어 **최댓값**을 확인해 비교할 필요 X
  - **현재 값보다 큰 값이 배열에 있는가?** 확인하면 됨
  - 현재 값보다 큰 값만 있으면 즉각 실행 중지 후 true를 반환하는 some 추천

## 회고

- 구조 분해 할당 문법을 의식을 가지고 활용하려 노력해야겠다. 오랜만에 보니까 이해하는데도 오래 걸렸음
- js 메서드가 별로 없는거 같다고 느끼면서도 막상 쓸 때는 생각이 안난다. 이렇게 계속 오답노트하며 배워야겠다.
- 배열 안에 내가 찾는 조건이 **단 하나**라도 있을 때 `some()` 사용하기~
  - 세부 예시로는
    - 권한 체크 및 차단
    - 장바구니 품절 등의 사유로 인한 결제 차단
    - 채팅 금지어로 인한 전송 차단 등

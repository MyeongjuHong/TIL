# 올바른 괄호

## 내 풀이

```js
function solution(s) {
  const arr = [];
  for (const char of s) {
    if (char === "(") {
      arr.push("(");
    }
    if (char === ")") {
      if (arr.at(-1) === "(") {
        arr.pop();
      } else arr.push(")"); // return false;
    }
  }
  return arr.length === 0 ? true : false;
  // return arr.length === 0;
}
```

## Best Practice

```js
function solution(s) {
  let count = 0;
  for (const char of s) {
    if (char === "(") {
      count++;
    } else {
      count--;
    }
    if (count < 0) return false;
    return count === 0;
  }
}
```

### 내 코드와의 차이

- 스택 방식:
  1. 여는 괄호가 나오면 `)` push
  2. 닫는 괄호가 나오면 `)` pop
  3. 닫는 괄호부터 시작시 `)` push
  4. 스택 비어있으면 true
- 카운터 방식:
  1. 여는 괄호와 닫는 괄호의 개수가 같음
  2. 닫는 괄호가 더 많아지면 안됨 (처음이어도)
  3. count 0이면 true
- 시간 복잡도는 둘 다 O(n)으로 같음
- 그러나 공간 복잡도는 스택은 배열(O(n)), 카운터는 변수(O(1))로 카운터가 더 공간 효율적
- 그러나 괄호의 종류가 다양하다면 스택으로 풀어야 함

### 일반 괄호문제 코드

```js
function solution(s) {
  const stack = [];

  const pair = {
    "}": "{",
    "]": "[",
    ")": "(",
  };

  for (const char of s) {
    // 여는 괄호
    if (char === "(" || char === "[" || char === "{") {
      stack.push(char);
    }

    // 닫는 괄호
    else {
      // 스택에 여는 괄호가 없으면 false
      if (stack.length === 0) return false;

      // 마지막에 열린 괄호에 맞는 닫힌 괄호가 아니면 false
      const top = stack.pop();
      if (top !== pair[char]) return false;
    }
  }

  return stack.length === 0;
}
```

## 다른 사람 풀이

```js
function solution(s) {
  let count = 0;

  for (const char of s) {
    count += char === "(" ? 1 : -1;
    if (count < 0) return false;
  }

  return count === 0;
}
```

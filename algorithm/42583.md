## 최종 풀이 

```js
function solution(bridge_length, weight, truck_weights) {
    var sec = 0;
    const onTheRoad = [];
    while (onTheRoad.length || truck_weights.length) {
        sec++;
        if (onTheRoad.length && (onTheRoad[0][1] + bridge_length === sec)) {
            onTheRoad.shift();
        }
        if ((onTheRoad.reduce((acc, cur) => acc + cur[0], 0) + truck_weights[0]) <= weight) {
            onTheRoad.push([truck_weights.shift(), sec]);
        }
    }
    return sec;
}
```

### 한 줄 요약

> 다리(queue)와 진입 전 트럭들(truck_weights)이 빌 때까지 매 회차 시간(초)을 올리며  
> 맨 앞 트럭의 진입 시간(onTheRoad[0][1])에 다리 길이를 더한 값이 현재 시간이면 진출(나갈 시간이니까)  
> 다리 위 트럭들의 무게와 다음으로 들어올 트럭 무게의 합이 최대 무게보다 적으면 진입

근데.. while 안에 무조건 실행되는 reduce 때문에 시간 복잡도가 $O(n^2)$   

> 트럭 무게를 그때그때 순회해서 더하기보다 진입하면 무게를 올리고, 진출하면 무게를 내리는 방향으로 디벨롭

## 지인 풀이

```java

import java.util.Queue; //import
import java.util.ArrayDeque;

class Solution {
    public int solution(int bridge_length, int weight, int[] truck_weights) {
        int answer = 0;


        Queue<Integer> queue = new ArrayDeque<>();
        int truckSum = 0; //다리위에 올라가 있는 트럭 무게


        for(int truck : truck_weights){


          while(true){

              if(queue.size() < bridge_length && weight >= truckSum + truck){   //길 위 자리도 남았고, 트럭 하나 올라가도 무게 충분하면

                  queue.add(truck);
                  truckSum += truck;
                  answer++;
                  break;
              }else{ // 길 위가 꽉 찼거나, 트럭 하나 올리기엔 무게 초과


                  if(queue.size() == bridge_length){ // 도로가 꽉차면 빼기

                      truckSum -= queue.poll();

                      if (weight >= truckSum + truck) { // 무게도 다시 한 번 확인해야 적재 가능
                            queue.add(truck);
                            truckSum += truck;
                            answer++;
                            break;
                        }

                  }else{
                      queue.add(0);
                      answer++;
                  }
              }
          }
        }
        return answer+bridge_length;
    }
}
```

### 한 줄 요약

> 다리(queue)에 진입할 수 있으면 트럭 무게 합(truckSum)에 추가, 무게는 남는데 다리가 꽉찬거면 진출시켜 트럭 무게 합에서 차감 후 진입, 자리는 있는데 무게가 꽉찬거면 다리에 0 추가

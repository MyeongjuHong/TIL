# 같은 숫자는 싫어

## 내 풀이

```js
function solution(arr) {
  const result = [];
  for (let el of arr) {
    if (el !== result.at(-1)) {
      result.push(el);
    }
  }
  return result;
}
```

## Best practice

```js
function solution(arr) {
  const result = [];
  for (let el of arr) {
    if (el !== result[result.length - 1]) {
      result.push(el);
    }
  }
  return result;
}
```

### 내 코드와의 차이

- at 메서드는 내부적으로 음수 인덱스를 계산하는 함수 호출 발생

## 다른 사람의 풀이

```js
function solution(arr) {
  return arr.filter((el, idx) => el !== arr[idx + 1]);
}
```

### 내 코드와의 차이

- 내 코드는 중복된 숫자 중 `맨 앞`만 `추가`
- 다른 사람의 코드는 중복된 숫자 중 `맨 뒤`만 `남김`
  - 그 뒤 요소와 `같으면 걸러지고 다르면 남김`
- `idx-1`이라면 중복된 숫자 중 `맨 앞`만 `남김`
  - 앞 요소와 `같으면 걸러지고 다르면 남김`

> filter는 콜백 함수가 원소마다 호출되기 때문에 일반적으로 `for` 보다 약간의 `오버헤드` 발생

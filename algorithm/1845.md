```js
function solution(nums) {
  const set = new Set();
  for (let i of nums) {
    set.add(i);
  }
  return set.size >= nums.length / 2 ? nums.length / 2 : set.size;
}
```

---

### 이렇게 푼 이유

- 갯수 상관 없이 선택 가능하면 배열의 번호 수만큼 선택 가능
- 중복 제거를 위해 Set 사용
- 오답으로 N/2 개수 제한을 반영해 length/2와 size 삼항연산자로 더 적은 수 반환

---

### 개선

```js
function solution(nums) {
  const kind = new Set(nums).size; // 반복문 필요없음
  const limit = nums.length / 2;

  return Math.min(kind, limit); // 둘 중 더 작은거 반환
}
```
